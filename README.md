# 🎬 Movie Recommender System

A content-based movie recommendation system built using Python and Streamlit.  
This project recommends movies similar to the one selected by the user based on similarity of content features like genres, keywords, cast, and crew.

---

## 📌 Features

- 🔍 Recommend similar movies from a preloaded dataset
- 🧠 Uses **cosine similarity** for accurate recommendations
- 💾 Fast access using preprocessed `.pkl` files
- 🖥️ Interactive **Streamlit** web interface
- 📚 Simple and clean UI with dropdown-based selection

---

## 🛠️ Tech Stack

- **Python**
- **Pandas, NumPy**
- **Scikit-learn**
- **Pickle**
- **Streamlit**

## 🚀 How to Run Locally

1. Clone the repo:
   git clone https://github.com/ksaini762/Movie-Recommender-System.git
   cd Movie-Recommender-System
2. Install
    pip install -r requirements.txt
3. Run the app
     streamlit run app.py
